# Hi, I'm Vivek Bhimani

Co-founder of [Asket Studio](https://asketstudio.in). I work on a project from start to finish: UI/UX design in Figma, building the website or app, and the SEO that gets it found once it's live.

Most of our clients are manufacturers (tile, solar and agriculture brands) that need a product catalogue on the web that loads fast, is easy to browse, and ranks.

## What I do

- **UI/UX design:** wireframes, design systems and app interfaces in Figma
- **Web development:** catalogue and brand sites in PHP and JavaScript, with GSAP for motion
- **App development:** Android apps
- **SEO:** technical audits, site structure, schema, Search Console and content strategy
- **Integrations:** WhatsApp API, e-commerce, custom internal tools
